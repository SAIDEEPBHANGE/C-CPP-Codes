# C and C++ Codes

This repository contains C and C++ examples covering data structures, algorithms, college exercises, and LeetCode problems. Source implementations are kept intact and organized by their subject.

## Repository layout

- [`Data-Structures/`](./Data-Structures/) contains trees, linked lists, stacks, queues, and graphs.
- [`Algorithms/`](./Algorithms/) contains searching, sorting, greedy, dynamic programming, and math examples.
- [`College-Codes/`](./College-Codes/) groups classroom exercises by topic.
- [`LeetCode/`](./LeetCode/) contains one folder per identified problem, with its source and a problem-specific README.

## Browsing LeetCode solutions

Open a numbered folder under [`LeetCode/`](./LeetCode/) to find `<number>.cpp` and its `README.md`. The README describes the solution's input or judge signature, logic, flowcharts, complexity, and how to run or submit it. Solutions whose problem number could not be uniquely verified are kept in [`LeetCode/Unidentified/`](./LeetCode/Unidentified/); see that folder's index for the descriptive names and identification evidence.

## How to use

Clone the repository:

```bash
git clone https://github.com/SAIDEEPBHANGE/C-CPP-Codes.git
```

Open the relevant topic folder and compile an individual source file with a C or C++ compiler when it is a standalone program. LeetCode class-method solutions are intended for the online judge unless their README says otherwise.
