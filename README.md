# C and C++ Codes

This repository contains C and C++ examples covering data structures, algorithms, college exercises, and LeetCode solutions. Existing source files are kept intact and grouped by their purpose so they are easier to browse and fetch.

## Repository layout

The documented structure is maintained in [`folder-structure.txt`](./folder-structure.txt).

```text
C-CPP-Codes/
|-- root examples
|-- College Codes/
`-- LeetCodeSolutions/
```

### Root examples

The root contains focused implementations of common data structures and algorithms:

- Data structures: linked lists, stacks, queues, binary search trees, and graphs.
- Algorithms: searching, sorting, Fibonacci sequence, knapsack, and longest common subsequence.
- Reference files: [`C-CPP-Codes-Structure.txt`](./C-CPP-Codes-Structure.txt) and [`Propmt.txt`](./Propmt.txt).

### College Codes

[`College Codes/`](./College%20Codes/) contains classroom exercises and experiments written in C and C++, including searching, sorting, memory allocation, networking formats, ciphers, and small games.

### LeetCodeSolutions

[`LeetCodeSolutions/`](./LeetCodeSolutions/) contains individual C++ solutions to LeetCode problems. Each file is kept as a standalone solution for quick lookup.

## How to use

Clone the repository:

```bash
git clone https://github.com/SAIDEEPBHANGE/C-CPP-Codes.git
```

Open the folder that matches the type of problem you want to study, then compile an individual source file with a C or C++ compiler. Most files are standalone examples and should be compiled independently.

## Organization policy

- Existing source code is not removed or rewritten during organization updates.
- Files remain in the categories defined by [`folder-structure.txt`](./folder-structure.txt).
- [`ACTION-PLAN.md`](./ACTION-PLAN.md) records the non-destructive organization plan.
